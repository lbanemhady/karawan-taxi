# دليل التشغيل الكامل — خطوة خطوة

هذا المجلد يحتوي على المشروع كاملاً وجاهزًا:
- `index.html` — الصفحة الرئيسية
- `dispatcher.html` — لوحة تحكم الشركة
- `driver.html` — تطبيق السائق
- `firebase-init.js` — ملف الربط بقاعدة البيانات (الوحيد اللي لازم تعدّله)
- `firestore.rules` — قواعد الأمان
- `README.md` — هذا الدليل

**كل الملفات مرتبطة ببعضها تلقائيًا ولا تحتاج "دمج" يدوي بالكود** — فقط حافظ عليها كلها داخل نفس المجلد الواحد كما هي، لأن كل صفحة تستدعي `firebase-init.js` من نفس المكان. إذا نقلت أي ملف لوحده بمجلد ثاني، التطبيق ما راح يشتغل.

---

## الجزء الأول: إنشاء قاعدة البيانات (مرة وحدة فقط)

### الخطوة 1: أنشئ حساب Firebase
1. افتح https://console.firebase.google.com
2. سجّل دخول بحساب Google (أو أنشئ واحد لو ما عندك).

### الخطوة 2: أنشئ مشروع جديد
1. اضغط **Add project** (أو **إضافة مشروع**).
2. اكتب اسم (مثلاً: `karawan-taxi`) واضغط **Continue**.
3. عطّل خيار Google Analytics (مو ضروري) واضغط **Create project**.
4. انتظر لين تنتهي، ثم اضغط **Continue**.

### الخطوة 3: فعّل قاعدة البيانات (Firestore)
1. من القائمة الجانبية اليسرى، افتح **Build** ثم **Firestore Database**.
2. اضغط **Create database**.
3. اختر أقرب موقع سيرفر جغرافيًا لك، اضغط **Next**.
4. اختر **Start in test mode** ثم **Create**.

### الخطوة 4: أضف تطبيق ويب واحصل على بيانات الربط
1. ارجع لصفحة المشروع الرئيسية (اضغط ⚙️ بجانب "Project Overview" أو أيقونة البيت).
2. اضغط أيقونة **</>‎** (Web) لإضافة تطبيق ويب.
3. اكتب اسم أي شي (مثلاً: `karawan-web`) واضغط **Register app**. **لا تحتاج** تفعّل Hosting بهذه الخطوة.
4. ستظهر لك شاشة فيها كود يحتوي على:
```js
const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "karawan-taxi.firebaseapp.com",
  projectId: "karawan-taxi",
  storageBucket: "karawan-taxi.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abcdef"
};
```
انسخ هذا الكائن كاملاً (كل القيم).
5. اضغط **Continue to console**.

### الخطوة 5: الصق البيانات بالمشروع
1. افتح ملف `firebase-init.js` بأي محرر نصوص (حتى Notepad يكفي).
2. استبدل القيم اللي مكتوب عليها `ضع_...` بالقيم الحقيقية اللي نسختها بالخطوة السابقة.
3. احفظ الملف.

### الخطوة 6: فعّل قواعد الأمان
1. من Firebase Console، افتح **Firestore Database** ثم تبويب **Rules**.
2. احذف المحتوى الموجود، وانسخ محتوى ملف `firestore.rules` كاملاً والصقه مكانه.
3. اضغط **Publish**.

✅ الآن قاعدة البيانات جاهزة ومربوطة بالملفات.

## الجزء الثاني: التجربة على جهازك قبل النشر

المتصفحات تمنع بعض الميزات (Firebase) عند فتح الملف مباشرة بنقرتين، فتحتاج "خادم محلي" بسيط (خطوة تقنية بسيطة جدًا، مرة وحدة).

**إذا عندك Node.js مثبت على جهازك:**
1. افتح Terminal (أو CMD على ويندوز) داخل مجلد المشروع.
2. نفّذ:
```
npx serve
```
3. افتح الرابط اللي يظهر لك (عادة `http://localhost:3000`).

**إذا عندك Python:**
```
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000`

**جرّب الآن:**
- افتح `index.html` (يفتح تلقائيًا أول صفحة عادة، أو اكتب `/dispatcher.html` بنهاية الرابط).
- افتح `dispatcher.html` وسجّل دخول بالرمز `1234`، وأرسل طلب تجريبي.
- افتح `driver.html` بتبويب أو جهاز ثاني، سجّل كسائق تجريبي، فعّل "متصل الآن"، واقبل الطلب.
- تأكد كل شي يشتغل صح قبل الانتقال للنشر.

## الجزء الثالث: النشر على الإنترنت (رابط حقيقي دائم)

هذا يعطيك رابط ثابت (مثل `https://karawan-taxi.web.app`) يفتح من أي جهاز بالعالم بدون ما يحتاج جهازك يكون مفتوح.

### الخطوة 1: ثبّت أداة Firebase (مرة وحدة فقط)
تحتاج **Node.js** مثبت على جهازك أولاً (نزّله مجانًا من https://nodejs.org إذا مو موجود). بعدها بـ Terminal/CMD نفّذ:
```
npm install -g firebase-tools
```

### الخطوة 2: سجّل دخول
```
firebase login
```
راح يفتح لك المتصفح لتسجّل بحساب Google نفسه اللي أنشأت فيه المشروع.

### الخطوة 3: اربط المجلد بالمشروع
داخل مجلد المشروع (نفس المجلد اللي فيه `index.html`)، نفّذ:
```
firebase init hosting
```
راح يسألك عدة أسئلة، جاوب كالتالي:
- **Please select an option:** اختر "Use an existing project" ثم اختر مشروعك (`karawan-taxi`).
- **What do you want to use as your public directory?** اكتب `.` (نقطة واحدة فقط) — لأن الملفات موجودة مباشرة بهذا المجلد.
- **Configure as a single-page app?** اكتب `N` (لا).
- **Set up automatic builds with GitHub?** اكتب `N` (لا).
- إذا سألك "File index.html already exists. Overwrite?" اكتب `N` (لا) — مهم جدًا لا تكتب y هنا حتى لا يمسح ملفك.

### الخطوة 4: انشر
```
firebase deploy
```
انتظر لين يخلص، وراح يطبع لك بالنهاية رابط مثل:
```
Hosting URL: https://karawan-taxi.web.app
```

🎉 هذا هو رابطك النهائي — افتحه وجرّبه، وشاركه مع السائقين والموظفين.

**لأي تحديث مستقبلي** (لو عدّلت أي ملف لاحقًا): فقط نفّذ `firebase deploy` مرة ثانية من نفس المجلد، ونفس الرابط يتحدّث تلقائيًا.

---

## قبل ما تشارك الرابط فعليًا — لا تنسَ:

1. **غيّر رمز دخول لوحة التحكم:** افتح `dispatcher.html`، دوّر عن `DISPATCHER_PIN = "1234"` وغيّره لرقم تختاره أنت، ثم أعد النشر (`firebase deploy`).
2. **اضبط الإعدادات:** من داخل لوحة التحكم (⚙️ الإعدادات) اكتب اسم شركتك، رقم هاتفها، قيمة الاشتراك اليومي، المناطق، والوجهات الشائعة.
3. **جرّب دورة كاملة حقيقية** (طلب → قبول → إنهاء → تسجيل دفعة) قبل ما تعطي الرابط لأي سائق حقيقي.
